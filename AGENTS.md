# Agent Instructions

This repository keeps AI instructions in `.ai/`.

Before making changes:

1. Read `.ai/README.md`.
2. Follow the loading rules in that file.
3. Load only the instruction files relevant to the requested change.
4. Always follow `.ai/instructions/coding-guidelines.md` for Kotlin code.

Do not duplicate AI instructions in this file. Keep this file as a stable entry point for tools that look for `AGENTS.md`.
